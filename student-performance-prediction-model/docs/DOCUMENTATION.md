## System Overview

The Student Performance Prediction Model is a core component of the AI-Powered Smart School Safety and Performance Monitoring System. It leverages historical academic data, attendance records, and demographic information to predict future marks with high precision.

### Key Features

- **RandomForest Regression**: Handles complex, non-linear relationships.
- **One-Hot Encoding**: Proper treatment of categorical subject data.
- **95% Confidence Intervals**: Professional uncertainty estimation for every prediction.
- **Feature Engineering**: Advanced indicators like `risk_index` and `attendance_score`.
- **Rest API**: Seamless integration with Laravel dashboards.
